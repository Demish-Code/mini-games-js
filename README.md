# 🎮 Интерактивный сайт мини-игр

Одностраничный адаптивный веб-сайт с 6 встроенными мини-играми, разработанный на чистом HTML, SCSS и JavaScript.

🚀 **Демо проекта (Deploy):** https://demishkevichd-code.github.io/2-nd-course-hw/

## 🛠 Используемые технологии
- **HTML5** (семантическая верстка)
- **SCSS / SASS** (архитектура БЭМ, Flexbox, CSS Grid)
- **JavaScript (ES6+)** (DOM API, обработка событий, математические функции)
- **CSS-анимации** (бесконечная бегущая строка `@keyframes`)
- **Git / GitHub Pages**

## 🎲 Реализованные мини-игры
1. Викторина
2. Угадай число
3. Простая арифметика
4. Переверни текст
5. Камень, ножницы, бумага
6. Генератор случайных цветов
